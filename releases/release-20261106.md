# Mario 0.6.0, Olimar 0.6.0 and Melee 0.5.0 - 2026-11-06

For Risk of Rain 2 **DLC4 (2026)** with BepInEx 5.4.21.0 and RoR2BepInExPack 1.46.0. Offline and friends-only co-op
only. Changes since hotfix-20261105-moon-gravity (Mario 0.5.8, Olimar 0.5.7, Melee 0.4.14).

The big change in this release is **where the mods live and where your discs go**. There is now one shared folder,
**SharedFiles**, for every disc and every extracted file. All three mods also have Thunderstore packages
(`wesleyasaurus-Mario`, `-Olimar`, `-Melee`, `-SharedFiles`).

## Updating from the previous release: do this first

Copying the new files over the old ones is **not** enough. The old folders would stay and load as a second copy of
each mod.

1. **Move your disc images somewhere safe** if they are inside an old mod folder (for example
   `BepInEx/plugins/MarioTest/`).
2. **Delete the old folders** in `BepInEx/plugins`:
   - `MarioTest`
   - `OlimarTest`
   - `Melee`
   - `gamecube_library.txt`, if you made one
3. **Install the new release.** By hand, merge this ZIP's `BepInEx` folder into your Risk of Rain 2 folder; it adds
   `wesleyasaurus-Mario`, `wesleyasaurus-Olimar`, `wesleyasaurus-Melee` and `wesleyasaurus-SharedFiles`. Or install
   the Thunderstore packages with r2modman; then also make sure the hand-installed folders are gone from the game
   folder.
4. **Put your disc images in `BepInEx/plugins/wesleyasaurus-SharedFiles/put_games_here/`**, under any file names.
   The mods look only there. `Paths.Disc`, `Paths.AssetsDir`, the other path settings, `assets_dir.txt` and
   `gamecube_library.txt` are not read any more.
5. **Start the game and let each mod extract once more.** This takes a minute or two per game, even if you had a
   cache: extracted files now record which extractor version made them, and old caches have no record. After that,
   an update re-reads a disc only when it changes how that disc's files are extracted. The old `assets` folders can
   be deleted.

Your settings are kept. The config files in `BepInEx/config` keep their names, and this release contains none. Their
old `[Paths]` lines are ignored.

**Unfinished characters are hidden now**: Fox, Luigi, Pikachu, Captain Falcon, Link and Donkey Kong (Melee) and
Bowser Jr. (Mario). To use them anyway, set `ShowUnfinished = true` in `BepInEx/config/Ror2Common.Experimental.cfg`
(created on the first launch) and restart.

**Multiplayer:** everyone needs these builds and the same `ShowUnfinished` setting. RoR2's mod-list check now
includes that setting.

`docs/Install.md` has the full guide.

## All three mods

- **SharedFiles.** Discs go in `put_games_here/`, directly or in one folder inside it. Extracted files go to
  `assets/pikmin`, `assets/sunshine` and `assets/melee`. A file one mod extracts is shared with the others, so
  nothing is extracted twice. For example, Mario's Luigi skin, Olimar's Captain Pikachu and the Melee mod all use
  `assets/melee`. There are no path settings.
- **Extractor versions.** Each game's `assets` folder records which extractor made its files. A future update that
  changes an extractor re-reads the disc by itself; without the disc, the mod keeps using the files it has.
- **Character portraits are lit evenly.** They use a key-and-fill light instead of one light that could leave them
  dark, with a hard shadow. Portraits are regenerated once.
- **Thunderstore packages**: `wesleyasaurus-Mario`, `wesleyasaurus-Olimar` and `wesleyasaurus-Melee`, each depending
  on `wesleyasaurus-SharedFiles`. The plugin folders now use those names.

## Mario 0.6.0 (native ABI 50)

- **Spinning ground pound:** A on its landing leaps 2.5 times as high as a plain pound's jump. This is the new
  setting `Sim.SpinPoundJump`. The landing also sweeps a ring of fire out to the shock wave.
- **Luigi strikes the Melee punch and kick poses** instead of playing his normal animation during them.
- **Mario extracts the Melee files he uses himself:** Luigi's skin without the Melee mod, and the punch and kick's
  file when the Melee mod is installed. Luigi's egg-lay move now waits until Yoshi's files are there.
- **The default skin icon is Mario's rendered portrait.**
- **Bowser Jr. stays hidden**, now behind `ShowUnfinished`. With it on, his brush attacks, voice and Gatekeeper
  are new.

## Olimar 0.6.0 (native ABI 64, unchanged)

- **Captain Pikachu's Melee files are checked in full**, including Pikachu's animation file, so an incomplete cache
  is repaired. Olimar extracts them himself; the Melee mod isn't needed.

## Melee 0.5.0 (native ABI 6, unchanged)

- **Samus and Yoshi only.** The other six fighters are hidden and their files aren't extracted unless
  `ShowUnfinished` is on. Each fighter's effects load only when that fighter's files are present.
- **Generated skill icons are kept in `SharedFiles/assets/melee/skill-icons/`.** They were in the plugin folder,
  which an update replaces.

Full per-mod lists are in `CHANGELOG.md`.
