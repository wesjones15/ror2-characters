# Mario 0.4.6, Olimar 0.4.2 and Melee 0.4.4

Piantissimo joins Mario's skins, alongside the already-released Luigi. All three mods now build with the committed shared `libcommon` implementations. These notes list changes since `release-20261025`.

## Mario 0.4.6

- **Unlock Piantissimo by beating the stage-four teleporter event as a living Mario.** He brings his Sunshine model and jump voice, pink/brown pound effects, and his own name and portrait while keeping Mario's moves and FLUDD. His remaining lines use Mario's voice pitched down 14%; `Sound.PiantissimoGameVoice` chooses his game-exact jump voice and silence otherwise.
- **Luigi remains unlocked with 2401 coins held at once as Mario.** He was introduced in 0.4.5; this release preserves that criterion and existing profile unlocks.
- Catching fire triggers the Sunshine burning bounce, voice, panic run and each skin's hot face.
- Spray flight speed increases from 1.2 to 1.4 times Sunshine's original speed.
- The statue descends vertically to its intended landing point, its fire placement is corrected, and portal playback resumes after handoff without advancing hidden playback.
- Effect textures retain independent mirror wrapping, and coin pickups draw the authored child sparkle.
- Rust disc/binary readers, textures, animation interpolation, AFC audio decoding and TEV arithmetic now use shared `libcommon` implementations.

Mario's released skins are Mario, Luigi and Piantissimo. The Peach and Mari-Yoshi viewer experiments are not registered as RoR2 skins in this release.

## Olimar 0.4.2

- Rust disc/binary readers, texture decoding, animation interpolation, AFC audio decoding and TEV arithmetic now use `libcommon`. Audio baseline tests compare against the pre-migration decoders.
- No intentional gameplay, balance, control or unlock changes.

## Melee 0.4.4

- Rust disc reading and animation interpolation now use `libcommon`, alongside the existing shared texture implementation.
- No intentional fighter move, balance, control or unlock changes.
- Extraction rejects source folders inside a checkout, using ignored cache rules without launching Git.

**Samus, Fox, Luigi and Yoshi remain the most complete Melee fighters.** Pikachu, Captain Falcon, Link and Donkey Kong are still in progress.

## Install or upgrade

1. Download **release-20261027.zip**, unblock it in Windows Properties if needed, and extract it.
2. Merge the included `BepInEx` folder into your mod-manager profile or the folder containing `Risk of Rain 2.exe`. Replace each component's two DLLs together.
3. The supplied config files contain release defaults. Skip `BepInEx/config` to preserve your settings and disc paths; new settings are added automatically on launch.
4. Each mod extracts assets from your own disc image: Super Mario Sunshine, Pikmin, or Super Smash Bros. Melee NTSC-U revision 2. Existing caches are reused; Luigi also requires the Melee asset cache. Set `Paths.Disc` if needed.

Requires RoR2 DLC4 (2026), Windows x64, BepInEx 5.4.21.0 and the dependencies in the included guides. The shared Rust code is built into the existing native DLLs; no additional runtime DLL is required. Mario uses native ABI 31, Olimar ABI 46 and Melee ABI 5. Install matching component builds for offline/friends-only co-op.

Automated/headless verification is included in the release process; these changes have not been played in RoR2. No disc images, extracted game assets, game DLLs or dependency DLLs are included. The ZIP includes guides, component changelog entries and a source/hash manifest, with a separate SHA-256 checksum.
